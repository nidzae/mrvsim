# Phase 6 status — Validation tests V1–V7 (TDD §9)

Date: 2026-09-30

## What was built

`mrvsim.validate` (comparison logic) with pytest wrappers in `tests/validation/` and a runner for the Validation panel:

- **`targets.py` / `data/fitted/validation_targets.yaml`** — every published comparison value with citation key and status (`ok` / `verify` / `missing`). Transcribed so far: the V3 intensities quoted in TDD §9 (Haynesville 0.79 % [0.63, 0.98], Permian 4.6 % [4.4, 4.9], status `verify`). V1 rate quantiles and persistence, V2 basin totals, the V3 boundary factor, and the VLMR ratio are `missing`.
- **`results.py`** — `ValidationResult` (pass / fail / skipped / error, compared values, reason, target status, `diagnostic_only`), JSON writer; `MRVSIM_ALLOW_PLACEHOLDER_VALIDATION` override.
- **`v1_rates.py`** — snapshot-censored facility rates > 10 kg/h per basin vs published quantiles (KS when a sample file is supplied; bootstrap quantile band otherwise); persistence vs Cusworth CI.
- **`v2_totals.py` + `feast_adapter.py`** — stratum-weighted basin totals vs published CIs; **FEAST 3.1 cross-check** (steady sources as constant emissions, intermittent sources through FEAST's episodic components, null LDAR program) within 15 %.
- **`v3_intensity.py`** — throughput-weighted basin intensity interval with the studies' aircraft mix vs published value; boundary-sensitivity placeholder.
- **`v4_stability.py`** — terciles vs quintiles, every headline metric within 2 × MC SE.
- **`v5_misspecification.py`** — truth from priors perturbed by α ± 0.3, μ ± 0.3, ν_on ± 0.5 (new `perturb_priors` helper); estimator keeps the base prior; κ ≥ 0.80 each; joint reported.
- **`v6_transient.py`** — 5 t/h × 6 h blowdowns at random times, six LEO satellites, satellite-only estimate = mean detected snapshot × duration; direction and order of magnitude.
- **`v7_calibration.py`** — default configuration at R replications; κ ∈ [0.85, 0.95] for both KPIs.
- **`runner.py`** — `run_all(quick=…)` → `runs/validation/<timestamp>.json`; `python -m mrvsim.validate.runner --quick`.
- **`vendor/feast`** — FEAST 3.1 (MIT) as a pinned submodule; numpy-2 aliases and a copy-safe `em_rate_in_range` are installed by the adapter at import, not by editing the vendored code.
