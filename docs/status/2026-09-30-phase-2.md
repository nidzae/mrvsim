# Phase 2 status — Sensor library (TDD §4)

Date: 2026-09-30

## What was built

`mrvsim.sensors`:

- **`pod.py`** — `PODCurve`: logistic in ln q_eff with wind exponent γ, u_ref, and `SurfaceAdjustment` φ (linear decline to 0.5 at the reflectance 10th percentile, clipped to [0, 1]; TDD §4.1 assumption with ±50 % uncertainty field). `prob()`, `pod_quantile()`, `pod50/pod90`, `sample_ab()` from a Laplace covariance, `ab_from_pod50_pod90()`.
- **`quantification.py`** — `QuantificationError(β, σ)`: `draw_reported`, `log_likelihood` (used by TDD §6.3), `ratio_interval`, `from_ratio_interval`.
- **`fit.py`** — `fit_pod_logistic(table, gamma, u_ref)`: maximum-likelihood (a, b) on ln q_eff with analytic gradient/Hessian, Laplace posterior covariance, weak ridge for separated tables, `PODFit.record()` for pasting into YAML as `fit_record`.
- **`schema.py`** — `Sensor` record with every TDD §4 field; `load_sensor` validates tiers, modes, citations (non-empty), provenance blocks, orbit block for satellites, and refuses Tier B–D sensors marked certifiable (PRD N2).
- **`library.py`** — `load_library()`, `certifiable(min_tier)`, `citation_keys()`, `reference_keys()` (parses REFERENCES.md), `unresolved_citations()` for the N1 check.

`configs/sensors/` — 13 sensor files: aircraft Bridger GML, Kairos, AVIRIS-NG/GAO (Tier A); satellites GHGSat-C, Sentinel-2, Landsat OLI, PRISMA, EnMAP (Tier A per TDD table), Tanager-1 and TROPOMI (Tier B, `enabled_for_certification: false`); CMS generic (Tier A detection, Tier C quantification, σ = 0.9), drone generic, OGI (Tier A). Each satellite has an orbit block (TLE name, NORAD id where known, swath, tasked flag) for Phase 3.

## Honest status of the numbers

**No block is `fitted`.** Every POD50/POD90, β/σ, false-positive rate, and cost is a `summary` or `assumption` value recalled from the literature while drafting, marked `TODO(verify)` with its citation key. `Sensor.unverified_blocks()` exposes this and the attribution panel must flag it. To upgrade a sensor: transcribe the paper's release table, run `fit_pod_logistic`, paste the record, set `status: fitted`. I recommend starting with El Abbadi et al. 2024 (aircraft) and Sherwin et al. 2023 (satellites), whose supplementary tables list per-release outcomes. The TROPOMI POD90 (8 t/h) was chosen to be consistent with the Phase 3 acceptance test (10 t/h detected on nearly every clear pass).
