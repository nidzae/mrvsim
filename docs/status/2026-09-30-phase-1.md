# Phase 1 status — Population generator (TDD §3)

Date: 2026-09-30

## What was built

`mrvsim.population`, fully vectorised over facilities and sources (CSR layout), returning a `Population` with true sources, hourly states, throughput, and conditions:

- **`strata.py`** — loads `configs/strata.yaml` (10 basins, 7 facility types, 21 basin×type cells × 3 terciles = 63 strata). `n_classes=5` switches to quintiles for V4. Fitted weights from `data/fitted/strata_weights.json` override the YAML placeholders when present.
- **`priors.py`** — loads `configs/priors/*.yaml` into per-cell `StratumPriors` (λ_h, p_h, μ/σ by type, q_tail, α, ν/τ on/off, throughput lognormals) plus per-basin `ConditionPriors`. `require_fitted()` raises `PlaceholderPriorsError` on PLACEHOLDER files; validation tests must call it.
- **`sources.py`** — K = Poisson(λ)+1; z ~ Bernoulli(p); lognormal rates with the Pareto tail spliced above q_tail (TDD §3.3).
- **`temporal.py`** — alternating renewal process with lognormal durations, exact stationary start (length-biased residual), hourly midpoint states, chunked vectorised generation; `StatePaths` bit-packs states (1/8 memory) with `state_at`, `state_at_pairs`, `on_hours`, save/load.
- **`throughput.py`** — V_gas from the cell lognormal truncated to the facility's quantile band (classes are terciles by construction); X_CH4; G_i; f_gas energy allocation; MMBtu; GHGRP-reporter flag. Constants in `configs/constants.yaml` with citation keys.
- **`conditions.py`** — monthly cloud fraction, surface reflectance/heterogeneity, monthly Weibull wind per facility from basin climatology plus seeded jitter.
- **`generate.py`** — `generate_population(cfg, seeds)`; truth accessors `true_mass_kg_yr`, `expected_mass_kg_yr`, `true_intensity`, `facility_rate_at(hours)`, `facility_rate_at_pairs`, `stratum_weights`, `citation_keys`, `save`.

Default sample: 6,300 facilities, ~21,300 sources, generated in **0.3 s**; packed states **23 MB** (TDD §10 budget: ≈50 MB).

- **Not fetched:** MODIS MOD08_M3 cloud climatology (needs `EARTHDATA_TOKEN`) and ERA5 10 m wind (needs `~/.cdsapirc`). Scripts are written and exit with status 2 explaining what to set. Placeholder climatologies stay in force.
- **Not attempted:** state production databases (per-state scraping; would refine well-pad counts).

- `test_population_temporal.py` (11): **duty-cycle identity** π = E[D_on]/(E[D_on]+E[D_off]) vs. realised on-fraction for four parameter sets; stationary start (first day = last day); run lengths ≈ E[D_on]; sub-hour cycles terminate; **bit-pack round trip**, paired queries, save/load; reproducibility.
